⭳ অ্যাপ ডাউনলোড করুন (Android) পুরনো ফোনের জন্য (32-bit) · For older phones

 

ইনস্টল করার নিয়ম · How to install

  1. উপরের লাল বোতাম চাপুন, ফাইলটি ডাউনলোড হবে। Tap the red button.
  2. ডাউনলোড শেষ হলে ফাইলটি খুলুন। Open the downloaded file.
  3. "Install unknown apps" চাইলে অনুমতি দিন, তারপর Install চাপুন। Allow "Install unknown apps" if asked, then Install.

নতুন সংস্করণ এলে অ্যাপই আপনাকে জানাবে। The app tells you when a new version is ready.
